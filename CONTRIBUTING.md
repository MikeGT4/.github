# Contributing

Issues and pull requests are welcome in every repository of this account.

For a bug, open an issue with the version, your system and the steps that lead to the problem. For a new idea, open an issue before you write code, so we can agree on the change first. Keep pull requests small, one change each, with tests where the repository has them.

Security problems do not go into a public issue. See [SECURITY.md](SECURITY.md).
